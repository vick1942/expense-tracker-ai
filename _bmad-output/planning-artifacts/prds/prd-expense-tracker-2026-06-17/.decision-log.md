## D-008 — Date filter recalculates summary for filtered period
**Date:** 2026-06-17
**Decision:** When a date range filter is active, the category summary reflects the filtered period, not always the current calendar month.
**Rationale:** More useful UX — a filter that changes the list but not the summary would be confusing.
**Status:** ASSUMPTION — confirm (see Open Question #5 in prd.md).
